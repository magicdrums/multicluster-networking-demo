### cloud-provider-kind (LoadBalancer)

Required for Skupper `linkAccess` and Gateway `EXTERNAL-IP` on Kind + Podman.

Install (pick one):

```bash
go install sigs.k8s.io/cloud-provider-kind@latest
# ensure $(go env GOPATH)/bin is on PATH, or:
# curl -sL <release asset> -o ~/.local/bin/cloud-provider-kind && chmod +x ~/.local/bin/cloud-provider-kind
```

Runtime (managed by `make up` / `make down`):

- Start: `KIND_EXPERIMENTAL_PROVIDER=podman cloud-provider-kind --enable-lb-port-mapping`
- After each **new** Kind create, demo-owned CCM is **restarted** so the site is adopted (and waited on for an EXTERNAL-IP).
- Gateway host ports: **west `:8080`**, **east `:8081`** (same listener port on both sites breaks host publish under rootless Podman).
- Pidfile: `demo/.run/cloud-provider-kind.pid`
- Log: `demo/.run/cloud-provider-kind.log`
- Owned marker: `demo/.run/cloud-provider-kind.owned` — `make down` stops CCM **only** when this marker is present
- After each Kind create: remove label `node.kubernetes.io/exclude-from-external-load-balancers` (single-node Kind)
